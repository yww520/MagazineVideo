# 高级杂志感视频转换

**Magazine-Grade Video**

把一段访谈或演讲，收成 **3:4** 的杂志感短视频。  
上面是 16:9 原片，画面上叠原语字幕；下面是跟嘴走的中文歌词式字幕，带刊头、栏头和纸面纪律。

> 这不是歌词播放器，也不是宣传片模板。  
> 它是一套**会动的编辑包装**：像品牌手册、研究报告，或夜灯下的独立杂志内页。

---

## 🎯 技能定位

本技能给 Cursor Agent 用，也给人读。接到「包装成杂志视频 / 竖版字幕视频 / 只有一条 YouTube 链接」这类需求时，按固定流程开工，而不是去复制旧片子目录。

| 它是 | 它不是 |
|---|---|
| 编辑包装：刊头、栏头、纸面、跟嘴字幕 | 热闹的宣传片、科技 HUD、玻璃拟态 |
| 内容与壳分离：新片只填文案和字幕 | 把上一集连同标题一起拷走 |
| 本地文件或视频链接都能开工 | 自动猜标题、节目名、页脚短链 |
| 两套皮肤共用同一套内容字段 | 为每支片子重做一套组件 |

画幅固定 **1080 × 1440（3:4）**，**30 fps**。原声保留，字幕跟口型走。

---

## ✨ 核心功能

- 📰 **两套杂志壳，一套内容模型**  
  暖奶油编辑风 / 墨绿刊印冷感风共用标题、页眉、页脚、中英字幕和高亮。换皮肤只换 `--style`。

- 📁 **本地文件入口**  
  给视频 + 中字 + 原语字幕 + 刊头四项，直接建实例、解析、出片。

- 🔗 **链接入口**  
  只给 Watch URL 也能做：`yt-dlp` 下全片，优先拿站点字幕，没有再本地 Whisper，然后按条译成中文。

- 👄 **碎片跟嘴**  
  中文字幕保持 YouTube 式短条，不拼成长句。只把「所以 / 对吧」这类残片并进前后条。

- 🪸 **珊瑚只点一次电**  
  只给真正有观点的碎片做高亮。一帧一处珊瑚，必须是该条原文的连续子串。

- ✂️ **默认不裁**  
  URL 里的 `&t=` 只写进页脚。用户明确要求截取某一段时，才传 `--start` / `--end`。

## 🎨 两套皮肤

两套壳共用 7 项内容和同一套字幕 / 高亮数据，只换气质。没选风格时，默认暖奶油编辑风。

| | 暖奶油编辑风 | 墨绿刊印冷感风 |
|---|---|---|
| 英文名 | Warm Cream Editorial | Cool Ink Letterpress |
| `--style` | `warm-editorial`（默认） | `ink-zine` |
| 气质 | 白天、判断、认真写下来的观点 | 夜间、沉浸、被刊印出来的句子 |
| 口诀 | 奶油是地，墨是声，珊瑚是电 | 墨是地，燕麦是声，珊瑚是电 |
| 场地 | 暖纸 `#EFE9DE` | 深墨绿 `#0E1D18` |
| 正文 | 近黑墨 `#141413` | 燕麦 `#F7E9D7` |
| 点火 | 珊瑚 `#CC785C` | 珊瑚 `#D9776A` |
| 字体 | 宋管思想 / 黑管说明 / 等宽管索引 | 华文宋 + Playfair，全衬线 |
| 适合说 | 研究报告、品牌手册 | 独立杂志、夜灯内页 |

两套都禁止发光、玻璃拟态、大渐变色块。珊瑚色一帧最多出现一次。

## 🔄 主要流程

命令在用户当前的 Remotion 项目根目录执行。技能只提供壳和脚本，片子写在那个项目里。

**套模板**和**填要素**不是另一步，也不是同一步：

| 你想的事 | 实际落在哪 |
|---|---|
| 按给定模板组装成一支可预览的片子 | **第 2 步建项目**：scaffold 写出实例并接上选中的壳。版式、纸面、滚动字幕区这时已经在，刊头还是空的 |
| 把视频、字幕、标题等要素填进去 | **第 3–8 步**：素材进 `public/`，刊头进 `content.ts`，字幕进 cue 文件，观点进 `highlights.ts` |

```
选风格 → 建项目（套模板）→ 取得素材 → 确认时长
    → 填刊头 → 译中文（仅链接入口）→ 解析字幕
    → 提炼高亮 → 注册预览脚本 → 静帧自检 → 交付
```

### 1. 选定风格

用户说了奶油纸 / 研究报告 → 暖奶油；说了墨绿 / 刊印 / 沉浸复古 → 墨绿。说不清就用暖奶油，不要为风格耽误开工。

### 2. 建项目（套模板）

```bash
node <技能目录>/scripts/scaffold.mjs \
  --slug <Slug> --comp <CompName> --style <warm-editorial|ink-zine>
```

这一步完成「按模板组装」：在当前 Remotion 项目里生成 `videos/<Slug>/`，把技能自带的壳挂进去，并写出 `Main` / `Root`，让这支片子直接渲染选中的皮肤。

此时版已经立好，**文案和素材还是空的**。不要改 `assets/` 里的组件来做新片。

### 3. 取得素材

| 入口 | 你给什么 | 技能补什么 |
|---|---|---|
| 本地 | 视频 + 中字 + 原语字 + 刊头四项 | 拷进 `public/` |
| 链接 | **视频 URL** + 刊头四项 | 下载、拿原语时间轴；中文下一步再译 |

链接路径产物：

- `public/media.mp4`
- `public/source.orig.srt`（画面叠层）

原语字幕优先级：**站点人工 → 站点自动 → 本地 Whisper**。不要跳过站点字幕直接转写。默认下全片；用户没要求截取，就不裁。

### 4. 确认时长

用 `ffprobe` 读 `media.mp4` 的真实秒数，后面写入 `content.ts` 的 `durationSec`。合成长度以视频为准，不按 YouTube 页面上的数字猜。

### 5. 填刊头

把用户给的四项写入 `src/content.ts`（再补上 `videoFile` 和上一步的时长）。这是「填要素」里的刊头部分：

1. 主标题（单行，约 16–22 字）
2. 页眉-视频原英文名
3. 页眉-节目名或频道名
4. 页脚-视频地址（Watch 链接可兼任此项）

不从 YouTube 标题、频道名或下载清单里猜这四项。缺就停下来问。

### 6. 译中文（仅链接入口）

本地入口用户已经给了中字，跳过。链接入口按条翻译 `source.orig.srt` → `source.zh.srt`：一条对一条，时间码原样拷贝，不为通顺合并或拆条。原语已经是中文则不要再译一遍。

### 7. 解析字幕

`parse-srt.mjs` 把中字和原语 SRT 写成 `subtitles.ts`、`en-subtitles.ts`（历史文件名，原语不一定是英语）。中文碎片跟嘴，只并「所以 / 对吧」这类残片。不要事后手改这两个文件。

### 8. 提炼高亮

读中文 cue，只给真正有观点的碎片写入 `highlights.ts`。一帧一处珊瑚，必须是该条原文的连续子串。没有观点的碎片可以不标。

### 9. 注册预览脚本

在项目 `package.json` 里加上这支片子的 `dev` / `render` / `still` 命令，端口避开已占用的。

### 10. 静帧自检

渲染开头、中段、结尾各一张，确认：主标题单行、中文字幕跟嘴不换行、珊瑚只点在有观点的短语上、画面内原语字幕对口型。

### 11. 交付

告诉用户预览命令 `npm run dev:<kebab>`，并说清用的是哪套风格（中文名 + 英文名）。

## 💡 设计亮点

### 会动的纸面，不是会动的 UI

暖奶油像品牌手册被翻开：发丝线、轻圆角、准星角标、低对比层次。  
墨绿像特种纸上的独立杂志：双细线、小菱形、纸粒和橄榄柔光已经在壳里，不用再堆装饰。

### 文字本身有表达力

每一帧一个焦点。主标题单行居中（墨绿）或单行刊头（暖奶油）；中文歌词当前句尽量不换行；闲置句降透明度，把视线留给正在说的那一句。

### 跟嘴，而不是「好读」

YouTube 式短条就是节奏。翻译时一条对一条、时间码原样拷贝；残片并入交给解析脚本，不为通顺去合并、拆条或重写时间轴。

### 珊瑚是电压，不是涂色笔

高亮可以是词、短语或短句，但必须是**这一条**原文的连续子串。没有观点的碎片可以不标。整条通体涂珊瑚，等于没有电压。

### 壳和集分离

模板在技能的 `assets/`。实例只改 `content.ts`、字幕和高亮。做新片不要去改已有片子目录里的文案。

## 🏗️ 技术架构

```
skills/magazine-grade-video/
├── SKILL.md                 ← Agent 开工说明书
├── README.md                ← 你正在读的这份
├── scripts/
│   ├── scaffold.mjs         ← 建实例 + 软链壳
│   ├── fetch-source.mjs     ← URL → 全片 + 站点字幕
│   ├── whisper-srt.py       ← 无站点字幕时的本地转写
│   └── parse-srt.mjs        ← 中/原语 SRT → cue
├── assets/                  ← Remotion 壳（随技能打包）
│   ├── types.ts             ← 共用 LyricContent / Cue / Highlights
│   ├── warm-editorial/src/  ← 暖奶油编辑风
│   ├── ink-zine/src/        ← 墨绿刊印冷感风
│   └── src/                 ← 旧路径兼容，指向暖奶油
└── references/              ← 两套视觉 guide，改模板时再读
```

技能本体在项目下的可见目录 `skills/magazine-grade-video/`。Cursor 仍从 `.cursor/skills/magazine-grade-video` 加载（指向这里的软链），所以 Agent 能找到，人也能在项目树里直接打开。

技能包是自包含的：壳、脚本、说明书都在包内，**不引用、不依赖某个工作区里的片子目录**。

### 内容与壳

壳在技能的 `assets/` 里。片子实例是 scaffold **写到用户当前 Remotion 项目**里的产物（`content.ts`、字幕、高亮），不是技能源码。

为了让实例能 import 壳、又不用把模板复制进每一集，scaffold 会在**那个项目**里建一个运行时别名，指向本技能的 `assets/`。别名只存在于用户项目，上传技能时不会带上。

每支片子是一个 Remotion Composition，目录由 scaffold 生成：

```
<项目>/videos/<Slug>/
├── public/media.mp4
├── src/content.ts          ← 刊头七项 + 时长
├── src/subtitles.ts        ← 中文 cue
├── src/en-subtitles.ts     ← 原语 cue（叠在画面上）
├── src/highlights.ts       ← 珊瑚短语
└── src/{Main,Root,index}
```

画面结构上下分栏：页眉 → 16:9 影像（原语字幕叠在画面内）→ 中文歌词滚动区 → 页脚。壳组件负责纸面和动效；实例不改组件，除非明确要求改模板。

### 字幕链路

```
本地 SRT 或 站点字幕 或 Whisper
        │
        ▼
 source.orig.srt  ──►  画面叠层（en-subtitles.ts）
        │
        ▼  Agent 按条翻译（时间码锁死）
 source.zh.srt    ──►  下方歌词（subtitles.ts）
        │
        ▼
 parse-srt.mjs 只并极短残片，再写 highlights.ts
```

链接下载默认全片。`--start` / `--end` 只在用户要求截取时出现；裁切时字幕时间轴会同步平移。

### 依赖

| 始终需要 | 链接入口额外需要 |
|---|---|
| Node.js、npm、Remotion | `yt-dlp`（`brew install yt-dlp`） |
| `ffmpeg` / `ffprobe` | 站点无字幕时：本地 `faster-whisper` |

本技能自包含，不把 youtube-clipper 整包拷进来。Whisper 只出跟嘴 SRT，不绑转 Word 的流程。

## 📦 你需要提供什么

缺刊头就停下来问，不要猜。

**一定要给**

- 主标题、页眉英文原名、节目名或频道名
- 视频文件，或一条视频 URL（Watch 链接可同时当页脚地址）

**本地入口还要给**

- 中文字幕 `.srt`
- 原语 / 英文字幕 `.srt`（也可从 mp4 软字幕抽出）

**可以不给**

- 关键词（技能从有观点的碎片里提炼）
- 风格（默认暖奶油编辑风）
- 截取时间（默认下全片）
- `mark` / `titleLine2`（墨绿壳的可选刊头记号和副行，没给就留空）
