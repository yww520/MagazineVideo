# 墨绿刊印冷感风 / Cool Ink Letterpress

可迁移的核心是「墨地、燕麦声、珊瑚电」。不是暖奶油编辑风的暗色版，而是深色独立杂志 / 刊印冷感。

## 1. 设计思想

像一本印在深色特种纸上的独立杂志被点亮，而不是一套 UI 皮肤。

- 文字本身有分量。表达靠宋体对比、字号层级和留白，不靠卡片、图标或动效堆料。
- 每一帧一个焦点。珊瑚只服务此刻最该被记住的那一下：一个词、一条进度、一枚刊头记号。
- 克制即高级。线用 1px 发丝线，装饰用小菱形，边框用双细线。禁止发光、玻璃、粗圆角色块、渐变按钮。
- 适合夜间、沉浸、被认真对待的判断。气质是刊印，不是宣传片，也不是科技 HUD。

## 2. 视觉气质

深墨、暖纸、刊头宋。冷绿底上是暖燕麦字，所以暗而不阴、旧而不脏。

- 像夜灯下翻开的杂志内页：场是深的，字是暖的，强调是干热的珊瑚。
- 表面有极轻的纸感（几乎看不见的点状颗粒 + 左上橄榄柔光），不要做成石板或纯黑。
- 层次靠透明度，不靠阴影：元信息约四成可见，闲置正文更淡，当前句全亮。
- 圆角只给被框住的影像，中文刊头保持锋利。
- 中文默认左齐。居中只给刊头主标题。

## 3. 背景色

整场是深墨绿色，不是青绿、不是黑。

| 角色 | 色值 | 用法 |
|---|---|---|
| 场色 Ink Green | `#0E1D18` | 整页底 |
| 柔光 Olive | 左上径向 `rgba(64,78,52,0.55)` | 避免死黑 |
| 压暗 Deep | `#0A1410` / 底部暗角 | 把视线压回中轴 |

底必须是带绿相的近黑，不能滑向青绿 teal、海军蓝或纯黑。柔光用橄榄，不用白光或珊瑚色光。颗粒透明度约 `0.04`。

## 4. 主色调与强调色

三色闭环，不要再引入第四品牌色。

| 角色 | 色值 | 职责 |
|---|---|---|
| 墨地 | `#0E1D18` | 地面 |
| 燕麦 Oat | `#F7E9D7` | 正文、发丝线、双线框 |
| 珊瑚 Coral | `#D9776A` | 刊头记号、小菱形、关键词底、已播进度 |

燕麦是主声，不是浅灰。元信息、闲置句用同一燕麦色降透明度。

珊瑚必须可数：关键词高亮是珊瑚底 + 燕麦字的短圆角印记。口诀：墨是地，燕麦是声，珊瑚是电。

## 5. 字体搭配

全衬线，不分发无衬线或等宽。

| 语言 / 层级 | 字体 | 气质 |
|---|---|---|
| 中文标题与正文 | Songti SC（华文宋体），回退 Noto Serif SC | 横细竖粗、刊头锋利 |
| 英文元信息、刊头、地址 | Playfair Display | 过渡衬线，杂志栏头 |

中文宋体负责思想，英文衬线负责栏头。不要用黑体做这套风格的中文。若没有华文宋体，用思源宋体 / Noto Serif SC 700–900，不要用楷、仿、圆体。
